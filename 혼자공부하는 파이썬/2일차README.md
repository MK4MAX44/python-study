## print() 함수

### 하나만 출력하기
```python
print("하나만 출력합니다.")
```

### 여러 개를 한 번에 출력하기
쉼표(`,`)로 구분하면 여러 값을 한 줄에 출력할 수 있다.
```python
print(10, 20, 30, 40, 50)
print("안녕하세요", "저의", "이름은", "전동혁입니다")
```

### 아무것도 출력하지 않기
인자 없이 `print()`만 호출하면 빈 줄이 출력된다. 확인용 구분선을 그릴 때 활용.
```python
print("--- 확인 전용선 ---")
print()
print()
print("--- 확인 전용선 ---")
```
