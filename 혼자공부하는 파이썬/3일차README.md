## 02-1 기본 자료형

### type()으로 자료형 확인하기
```python
print(type("안녕하세요"))   # <class 'str'>
print(type(52.333))        # <class 'float'>
print(type(True))          # <class 'bool'>
```

### 문자형 (str)
문자, 단어, 문장 등 텍스트를 표현하는 자료형.

### 숫자
- 정수 ➢ `int` (Integer)
- 실수(부동소수점) ➢ `float` (Floating point)

### 불 (bool)
참(`True`) / 거짓(`False`) 두 가지 값만 가지는 자료형.

### 복합 자료형
기본 자료형이 복합적으로 섞여 있는 것.

## 문자열 만들기 기본
문자형을 만들 때 큰따옴표(`"`)와 작은따옴표(`'`) 구분이 없다.
```python
"안녕하세요"
'안녕하세요'
```
- `""` : 문자열 리터럴
- 안녕하세요 : 식별자
- `"라고 말했습니다"` : 문자열 리터럴

## 이스케이프 문자 사용하기
문자열 안에 따옴표를 그대로 넣고 싶을 때는 `\"`로 이스케이프한다.
```python
"안녕하세요라고 말했습니다"
"\"안녕하세요\"라고 말했습니다"
```

## 문자열 연산자 (8강)

### 연결 연산자 (+)
```python
print("문자열" + "문자열")   # 문자열문자열
```

### 반복 연산자 (*)
```python
print("문자열" * 3)   # 문자열문자열문자열
print(3 * "문자열")   # 문자열문자열문자열
```

### 인덱싱 — 문자 하나 선택 `문자열[인덱스]`
인덱스는 0부터 시작, 음수 인덱스는 뒤에서부터 (`-1`이 마지막 글자).
```python
word = "안녕하세요"
print(word[0])    # 안
print(word[3])    # 세
print(word[-1])   # 요
```

### 슬라이싱 — 범위로 자르기 `문자열[시작:끝]`
`시작` 이상 `끝` 미만 범위를 잘라낸다. 앞/뒤를 생략하면 "처음부터" / "끝까지".
```python
print(word[0:3])  # 안녕하 (끝 인덱스 3은 포함 안 됨)
print(word[:3])   # 안녕하 (처음부터 3 직전까지, 위와 동일)
print(word[3:])   # 세요   (3번째부터 끝까지)
print(word[:])    # 안녕하세요 (전체)
```

### 스텝(증가값) 슬라이싱 `문자열[시작:끝:스텝]`
스텝만큼 건너뛰며 잘라낸다.
```python
numbers = "0123456789"
print(numbers[::2])  # 02468
print(numbers[::3])  # 0369
print(word[1:4:2])   # 녕세 (인덱스 1, 3만 선택)
print(word[::2])     # 안하요
```

### 용어 정리
- **인덱스(index)**: 문자열 안 위치를 나타내는 숫자
- **인덱싱(indexing)**: `문자열[인덱스]`처럼 인덱스 하나로 문자 한 개를 뽑는 것
- **슬라이싱(slicing)**: `문자열[인덱스:인덱스]`, `문자열[인덱스:인덱스:스텝]`처럼 범위로 잘라내는 것
