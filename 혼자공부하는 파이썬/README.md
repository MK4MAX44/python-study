# 혼자 공부하는 파이썬 - 1일차

## 표현식 (Expression)
어떤 값을 만들어내는 코드.

## 리터럴 (Literal)
코드 안에 직접 쓰인 값 자체.
```
10
20
30
```

## 식별자 (Identifier)
기호를 빌려서 값을 표현하는 것. 예: `π = 3.141592`

### 파이썬이 강제하는 규칙
1. 키워드를 사용하면 안 된다
2. 특수문자는 `_`만 허용된다
3. 숫자로 시작하면 안 된다
4. 공백을 포함할 수 없다

### 개발자들끼리 약속한 규칙 (관례)
- 왠만하면 영어로 작성
- 예: `input`(입력), `output`(출력)

## 연산자 (Operator)
```
+  -  *  /  %
** //
and  or  not  in
```

## 키워드 (Keyword)
파이썬이 만들어질 때 정의된 특별한 의미를 가진 단어.
```
False, None, raise, or ...
```

## 네이밍 컨벤션

### 스네이크 케이스 (snake_case)
공백을 `_`(언더바)로 교체.
```
send to user → send_to_user
```

### 캐멀 케이스 (camelCase)
- 모든 단어의 첫 글자를 대문자로 결합: `SendToUser` (파이썬에서는 사용하지 않는 방식)
- 두 번째 단어부터 대문자로 결합: `sendToUser`

### 한 글자 단어 구분 예시
- `animal` → 스네이크 케이스
- `Animal` → 캐멀 케이스
